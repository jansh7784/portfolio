> **Welcome!**  
> This is the source code for my personal portfolio, featuring my work, skills, and journey.  
> Designed with passion, optimized for speed, and themed for impact.

---

## 🪄 Features

- **Modern Design** – Sleek, minimal, and responsive for all devices.
- **Vibrant Theme** – Elegant gradients, glassmorphism, and dark mode.
- **Lightning Fast** – Powered by Vite & optimized build.
- **Showcases Projects** – Interactive cards and live previews.
- **Animated Interactions** – Subtle transitions and micro-animations.
- **SEO & PWA** – Ready for search engines and installable on mobile.

## 🛠️ Tech Stack

| Frontend      | Build Tool   | Styling        | Quality    | Deployment   |
|---------------|--------------|----------------|------------|-------------|
| TypeScript    | Vite         | Tailwind CSS   | ESLint     | Vercel      |

## 🚀 Getting Started

### 1. Clone the repo

```sh
git clone https://github.com/jansh7784/portfolio.git
cd portfolio
```

### 2. Install dependencies

```sh
npm install
```

### 3. Run for development

```sh
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) to see your local copy.

### 4. Build for production

```sh
npm run build
```

### 5. Preview production build

```sh
npm run preview
```
